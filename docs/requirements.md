# Beatstore — требования к первой версии

Документ описывает бизнес-правила и функциональность первой версии магазина. Юридические условия оформляются отдельными договорами.

## Цель и ограничения

- Магазин одного продюсера для клиентов РФ, русский язык, рубли.
- Продавец планирует принимать платежи как самозанятый.
- Срок: два месяца; участие владельца: 6–7 часов в неделю.
- Начальный каталог: 100–200 товаров; биты и драмкиты.
- Одна покупка — один товар и один выбранный вариант лицензии.
- Один платёжный сервис; конкретный сервис предстоит выбрать.
- Нет корзины, фильтров, маркетплейса, подписок и бонусной программы.
- Прослушивания не отслеживаются автоматически. Роялти учитываются и выплачиваются вне сайта.

## Аккаунты и экраны

- Посетитель просматривает каталог, ищет по названию и слушает полный бит. Голосовая метка необязательна.
- Для любых покупок и бесплатного скачивания нужна регистрация с паролем.
- Требуется восстановление пароля.
- Главная страница — каталог с карточками и поиском.
- Из каталога доступны вход/регистрация либо личный кабинет, а также полная карточка товара.
- Оформление заказа открывается только из полной карточки товара.
- После входа пользователь возвращается к выбранному товару и действию.
- Кабинет покупателя содержит приобретённые товары, файлы и условия покупки; незавершённые заказы отображаются отдельно.
- Администратор использует общий механизм входа и кабинет с другим содержимым.
- Создание товара доступно из кабинета администратора.
- Редактирование открывается специальной кнопкой из полной карточки товара.
- Права на операции проверяются на сервере.

## Лицензии на биты

| Вариант | Базовая цена | Файлы |
| --- | ---: | --- |
| MP3 | 1 000 ₽ | MP3 |
| WAV | 2 000 ₽ | WAV без MP3 |
| TRACKOUT STEMS | 3 000 ₽ | ZIP отдельных дорожек WAV, без цельного WAV и MP3 |

- Администратор задаёт одну процентную скидку для трёх неэксклюзивных вариантов конкретного бита.
- Дополнительных платных условий нет.
- Лицензии бессрочные; разрешены музыкальные площадки и радио; указание авторов обязательно.
- Лимит: 500 000 прослушиваний одного трека с битом на каждой площадке отдельно.
- Лицензия прекращается при превышении лимита хотя бы на одной площадке.
- Если эксклюзив доступен, для продолжения использования покупатель обязан приобрести его.
- После эксклюзивной продажи ранее приобретённые платные лицензии сохраняются до превышения лимита. Новый правообладатель принимает это условие.
- Магазин не определяет превышение автоматически. Доступ к приобретённым файлам и право использования — отдельные понятия.

## Бесплатный MP3

- Доступен зарегистрированному пользователю для использования без монетизации, включая YouTube, SoundCloud и TikTok.
- Перед первым бесплатным скачиванием конкретного бита показываются краткие условия.
- Сохраняются пользователь, бит, дата принятия и версия условий.
- После эксклюзивной продажи новые бесплатные скачивания прекращаются; бесплатное разрешение также прекращается.

## Эксклюзив

- Покупается автоматически по индивидуальной цене бита, без согласования с продавцом.
- Скидка обычных лицензий на эксклюзив не распространяется.
- Выдаётся только ZIP проекта FL Studio.
- Сторонние плагины и библиотеки могут быть необходимы; продавец не обеспечивает их наличие у покупателя. Требования к проекту показываются до оплаты.
- Авторство сохраняется за первоначальными авторами.
- Процент роялти задаётся при создании товара и сохраняется в приобретённых условиях.
- База роялти: только доход от стриминга после комиссий.
- Отчётность и выплаты — по календарным кварталам, вне сайта.
- Нельзя продать эксклюзив двум покупателям.

## Драмкиты

- Архив до 500 МБ; цена и процентная скидка задаются для каждого товара.
- Покупка не предусматривает отдельного договора; перепродажа и распространение архива запрещены.
- Условия коммерческого использования звуков находятся в текстовом файле внутри архива.
- Показ условий использования звуков до оплаты остаётся открытым вопросом.

## Состояния товара

| Состояние | Поведение |
| --- | --- |
| Черновик | Видит только администратор, покупки недоступны |
| Опубликован | В каталоге, доступны превью и покупка |
| Снят с публикации | Новые покупки и бесплатные скачивания недоступны; прошлые покупки сохраняются |
| Эксклюзив продан | Новые продажи и бесплатные скачивания прекращены; повторная публикация запрещена |

- Товар без покупок можно удалить окончательно с подтверждением.
- Товар с покупками снимается с публикации; заказы, условия и оплаченные файлы сохраняются.
- При резерве эксклюзива временно прекращаются новые покупки всех лицензий бита.
- Ранее начатые обычные оплаты должны завершиться либо истечь до открытия оплаты эксклюзива.
- При неуспешной оплате эксклюзива резерв снимается. Срок резерва и обработка запоздалых платежей зависят от возможностей платёжного сервиса.

## Состояния заказа и надёжность

| Состояние | Поведение |
| --- | --- |
| Ожидает оплаты | Сохранены товар, вариант, цена и условия; файлы не выдаются |
| Оплачен | Оплата подтверждена сервисом; покупка и файлы доступны |
| Отменён | Покупатель отменил заказ либо срок оплаты истёк; файлы не выдаются |
| Возвращён | Подтверждён возврат; дальнейшее использование определяется условиями покупки |

- Возврат на старте оформляется вручную через платёжный сервис.
- Переход браузера со страницы оплаты не подтверждает платёж.
- Повторное уведомление платёжного сервиса не создаёт повторную покупку.
- Цена и версия условий фиксируются при оформлении заказа; редактирование товара их не меняет.
- Чужие заказы и файлы недоступны пользователю.
- Купленные файлы доступны для повторного скачивания, включая товары, снятые с публикации.

## Открытые вопросы перед запуском

1. Срок предоставления отчёта и выплаты после окончания календарного квартала.
2. Финальная юридическая проверка договоров и модели передачи прав, правила прекращения использования опубликованного трека.
3. Конкретный платёжный сервис, подключение самозанятого и выдача чеков.
4. Сроки резервирования и безопасная обработка запоздавших платежей.
5. Показ условий использования звуков драмкита до оплаты.
