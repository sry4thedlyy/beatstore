# Шрифты документов

Noto Sans Regular и Bold используются только на сервере для PDF с русским текстом. Шрифты включены в документ подмножеством символов; загрузка шрифтов из сети при генерации не требуется.

Источник: [официальный репозиторий Noto Fonts](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans). Лицензия SIL Open Font License 1.1 сохранена в `OFL.txt`.
